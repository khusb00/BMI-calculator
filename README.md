# BMI-calculator
A web-based application that calculates Body Mass Index (BMI) using HTML, CSS, and JavaScript.

# Features
- BMI Calculation: Calculates BMI based on user-inputted height and weight.
- Result Display: Displays the calculated BMI and corresponding weight status (e.g., underweight, normal weight, overweight, obese).
- User-Friendly Interface: Simple and intuitive design for easy use.

# Technologies Used
- HTML: Defines the structure and content of the calculator.
- CSS: Styles the layout, typography, and visual design.
- JavaScript: Handles user input, calculates BMI, and updates the result display.

# How it Works
1. User inputs their height and weight.
2. The application calculates BMI using the formula: BMI = weight (kg) / height (m)².
3. The calculated BMI is displayed along with the corresponding weight status.

# Notes
- Client-Side Calculation: The BMI calculation is performed on the client-side using JavaScript.
- Simple and Intuitive: Designed for easy use and understanding.
